### Defects found and fixed

Each of these would have produced a wrong number silently:

1. **`CostTracker` priced every Claude call at Haiku rates.** An Opus-5 judge
   would have been costed at one fifth of actual, and the budget cap would not
   have fired until five times the stated limit. Now priced per model, and it
   raises on an unpriced model rather than guessing.
2. **Judge resume froze API failures as permanent.** A row the judge failed on
   was stored as ungradable and never retried, so a rate-limit blip would
   silently remove those queries from the analysis forever.
3. **`run_phase_e` never passed `ckpt_path`**, which AlignScore requires. The
   phase would have crashed the first time anyone installed the package;
   invisible until then because the import guard was skipping it.
4. **Perturbation regex rejected sentence-final numbers.** `$1,000.` never
   matched, so the experiment would have run on an unrepresentative slice.
5. **`1000` was classified as a year** and perturbed by 0.7% instead of 50% —
   biased toward the conclusion being tested, which is the wrong direction.
6. **Claim splitter dropped three-word claims.** A dropped claim is invisible
   to a minimum, so short fabrications — exactly what the metric exists to
   catch — would have been hidden.
7. **Four tests needed `transformers`** and passed on the old laptop only
   because it happened to be installed. Now skip cleanly.

## 3. Results, in one page

**Retrieval quality** (NDCG@5): NQ spread 4.4 points, HotpotQA 11.9 points.
The ranking differs between datasets.

**The verdict on faithfulness depends on the evaluator.** Same queries, same
answers, same refusal handling, same test:

| dataset / generator | NLI-max | AlignScore |
|---|---|---|
| NQ / Claude | 0.0090, p=0.223 null | 0.0179, **p=0.0005** |
| NQ / GPT-4o-mini | 0.0129, p=0.099 null | 0.0080, p=0.118 null |
| HotpotQA / Claude | 0.0190, p=0.270 null | 0.0126, p=0.151 null |
| HotpotQA / GPT-4o-mini | 0.0267, p=0.065 null | 0.0461, **p=0.0005** |

**Direction splits by dataset, not by evaluator.** All four HotpotQA cells
correlate positively with NDCG@5 (rho +0.40 to +1.00); all four NQ cells are
zero or negative.

**Evaluator sensitivity to a falsified value**, detection at a 0.5 threshold:

| | NLI-max | Claim-min | AlignScore |
|---|---|---|---|
| NQ / Claude | 4% | 23% | 29% |
| NQ / GPT-4o-mini | 58% | 63% | 76% |
| HotpotQA / Claude | 13% | 33% | 45% |
| HotpotQA / GPT-4o-mini | 70% | 70% | 90% |

Mechanism: the score decays as answers accumulate assertions. Claude averages
2.99 per answer, GPT-4o-mini 1.18. Verbatim copying was tested as an
alternative explanation and rejected — overlap is 0.234 for both generators
and correlates the wrong way.

**Consequence for the equivalence claim.** Falsifying one grounded value moves
NLI-max by 0.033–0.094, so a TOST margin of ±0.05 is about the size of one
fabricated fact. The margin is now reported as a curve from ±0.01 to ±0.10.
